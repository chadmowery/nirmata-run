    Update the `destroyEntity` method in `src/engine/ecs/world.ts` to support recursive deletion of child entities.
    
    Before removing the entity from `this.entities` and deleting it from `this.stores`, fetch its `children` component data:
    ```typescript
    const childrenStore = this.stores.get('children');
    if (childrenStore && childrenStore.has(id)) {
      const childrenData = childrenStore.get(id) as { entityIds: number[] };
      for (const childId of childrenData.entityIds) {
        this.destroyEntity(childId);
      }
    }
    ```
    Place this recursion block at the beginning of `destroyEntity` so children are safely deleted before the parent's component stores are wiped.
