    In `src/engine/entity/types.ts`, update the `RawTemplate` interface to include the `children` array definition:
    ```typescript
    children?: { template: string; slotComponent: string; overrides?: Record<string, Record<string, unknown>> }[];
    ```

    In `src/engine/entity/builder.ts`, modify `buildEntity` to accept `templateRegistry` and `children`:
    ```typescript
    export function buildEntity<T extends EngineEvents>(
      world: World<T>,
      templateName: string,
      resolvedComponents: Record<string, unknown>,
      componentRegistry: ComponentRegistry,
      templateRegistry: EntityRegistry,
      children?: RawTemplate['children']
    ): EntityId { ... }
    ```
    
    Inside `buildEntity`, after standard components are stamped, process the children:
    1. Initialize a `childIds` array.
    2. Iterate over the `children` parameter. For each child:
       - Fetch its template from `templateRegistry`.
       - Create a cloned template applying `child.overrides`.
       - Resolve mixins for the child.
       - Recursively call `buildEntity` to create the child entity.
       - Add the `Parent` component to the child entity targeting the `entityId` and `child.slotComponent`.
       - Push the resulting child ID to `childIds`.
    3. If `childIds` has items, add the `Children` component to the `entityId` containing the array of child IDs.
    
    In `src/engine/entity/factory.ts`, update `EntityFactory.create` to pass `this.registry` and `template.children` down to `buildEntity`.

    Update `src/engine/entity/builder.test.ts` to include a test `"should recursively instantiate children and link them via Parent and Children components"`.
