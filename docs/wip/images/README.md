# Concept Art Index & Visual Breadcrumbs

> **Note on Image Assets**: Generated concept plates (`watermarked_img_*`) are managed by the chat runtime environment and are embedded in the markdown documents using standard markdown image tags. When viewing in compatible viewers or exporting, download or copy the image assets directly from the chat session into this folder.

### 4. Concept Plate 4 — 4-Faction Corporate Biome Moodboard (Megastructure & Cabling)
- **Reference ID:** `watermarked_img_6084510415740805834.jpg`

- **Prompt Core:** 4-quadrant megastructure moodboard with monumental architecture, dense cabling, and *Replaced*-style volumetric atmosphere:
  - **Quadrant 1 (Top-Left):** *Traxus Heavy Foundry* — Colossal smelting towers, heavy cable bundles suspended from ceiling trusses, glowing molten orange slag rivers, and yellow hazard chevrons.
  - **Quadrant 2 (Top-Right):** *Sekiguchi Gene-Labs* — Monolithic cleanroom pillars, gigantic glowing emerald cryo-cylinders, dense waterfalls of black umbilical hoses, mirror-like wet floor reflections, cold volumetric mist.
  - **Quadrant 3 (Bottom-Left):** *CyberAcme Mainframe* — Brutalist server canyons fading into midnight void, massive overhead conduit trunks, and vibrant laser-cyan circuit buses.
  - **Quadrant 4 (Bottom-Right):** *NuCaloric Bio-Storage* — Geometric polymer silos, sprawling networks of magenta and chartreuse nutrient pipes wrapped in industrial cable ties, and dense refrigerated fog.
