## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #000000 (black) | Background, game world surfaces |
| Secondary (30%) | rgba(0, 20, 0, 0.85) | Panel backgrounds, overlay backgrounds (rgba(0,0,0,0.90)) |
| Accent #1 (5%) | #00F0FF (neon cyan) | "Secure" actions (EXTRACT, success states), Tier 1 enemy particles |
| Accent #2 (5%) | #FF0055 (electric pink) | "Risk" actions (DESCEND, danger states), Tier 2 enemy particles, sprite ghosting trails |
| Destructive | #FF0055 (electric pink) | RESTORE DEFAULT confirmation, destructive run-ending choices |
| Alert | #FF9500 (safety orange) | BSOD death screen, critical system failures |

**Source:** `src/app/globals.css` lines 14-26 (Vibrant Decay palette + semantic tokens)

**Accent reserved for:**
- **Cyan (#00F0FF):** EXTRACT button, success messages, "safe zone" Heat states (0-99), Tier 1 enemy neon particles, positive feedback geometry flashes
- **Pink (#FF0055):** DESCEND button, danger warnings, Corruption Zone Heat states (100+), Tier 2 enemy neon particles, sprite ghosting trails, screen-tear effects
- **White (#FFFFFF):** Tier 3 enemy neon particles (hot white radiance), text overlays, high-contrast UI elements
- **Safety Orange (#FF9500):** BSOD death screen background only

Accent colors are NEVER used for generic interactive elements like standard buttons, links, or form inputs. They signal risk/reward choices and enemy threat levels.

## Interaction Patterns

| Pattern | Behavior | Feedback |
|---------|----------|----------|
| Heat tier crossing | Discrete visual snap when Heat crosses threshold (50, 80, 100, 120, 160) | Instant filter application (no fade), unmistakable sensory shift |
| Heat tier exit | Instant filter removal when Heat drops below threshold (dissipation/venting) | Immediate relief feedback, no lingering effects |
| Enemy damage | Pixel scatter outward + 1-2 text fragments float up and fade over 500ms | Reinforces "corrupted process leaking data" theme |
| Augment trigger | High-contrast geometric shape flashes center-screen for ~300ms + message log entry | Clear synergy confirmation without interrupting combat flow |
| RESTORE DEFAULT click | Modal confirmation overlay with RESET/CANCEL | Prevents accidental loadout wipes, electric pink destructive styling |
| Kernel Panic trigger | Cumulative visual degradation per tier (jitter → inversion → screen-tear → grayscale) | Persistent until Heat drops below tier threshold |

**Key principle:** Visual effects are immediate and discrete at tier boundaries, not gradual. Crossing from 99 Heat to 100 Heat (Corruption Zone entry) inverts the screen color instantly. Player knows they're in danger.

## State Visualization

| State | Visual Treatment |
|-------|------------------|
| Heat 0-49 (Clean) | Clean cyan HUD, no effects |
| Heat 50-79 (Jitter) | HUD jitter (CSS shake/offset), cyan HUD maintained |
| Heat 80-99 (Ghosting) | HUD jitter + sprite ghosting (pink pixel trail on player sprite) |
| Heat 100-119 (Inversion) | All previous + color inversion (PixiJS ColorMatrixFilter on game world) |
| Heat 120-159 (Screen-tear) | All previous + screen-tearing (PixiJS GlitchFilter on stage) |
| Heat 160+ (Grayscale) | All previous + grayscale world (PixiJS desaturation) + constant feedback |
| Enemy Tier 1 (Corrupted Data) | Cyan neon particle emission, cyan pixel scatter on damage |
| Enemy Tier 2 (Static Horrors) | Pink neon particle emission, pink pixel scatter on damage |
| Enemy Tier 3 (Logic Breakers) | White/hot-white neon particle emission, white pixel scatter on damage |
| Death (any cause) | Safety Orange BSOD full-screen overlay with failure reason in black uppercase text |
| Augment synergy trigger | White triangle or orange square flash center-screen (~300ms) + message log entry |

**Filter stacking:** Heat tier effects are cumulative. At Heat 160, the player experiences jitter + ghosting + inversion + screen-tear + grayscale simultaneously. This creates escalating sensory overload matching the Kernel Panic risk curve.

## Accessibility Notes

- **High contrast:** Vibrant Decay palette (#00F0FF cyan, #FF0055 pink, #FF9500 orange on #000000 black) exceeds WCAG AAA contrast ratios for all text and interactive elements.
- **Motion sensitivity:** Heat tier visual effects (jitter, screen-tear, inversion) are core gameplay feedback and cannot be disabled without removing critical risk information. Future enhancement: add accessibility setting to reduce effect intensity while preserving tier boundaries.
- **Color dependence:** Tier identification relies on color (cyan/pink/white neon particles). Future enhancement: add secondary non-color cues (particle size, emission frequency, enemy silhouette detail).
- **Terminal aesthetic:** Uppercase condensed typography and high-contrast colors are intentional sci-fi terminal design language, not accessibility oversights.
